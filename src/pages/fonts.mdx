# 字体与许可

本站字体随网站提供，无需额外安装。

| 用途 | 字体 | 许可 |
| --- | --- | --- |
| 姓名、英文标题、导航、英文正文 | [Inter](https://github.com/rsms/inter) | <a href={useBaseUrl('/fonts/inter/LICENSE.txt')}>SIL OFL 1.1</a> |
| 日期、编号、标签、代码 | [IBM Plex Mono](https://github.com/IBM/plex) | <a href={useBaseUrl('/fonts/ibm-plex-mono/LICENSE.txt')}>SIL OFL 1.1</a> |
| 中文 | [霞鹜新晰黑屏幕阅读版](https://github.com/lxgw/LxgwNeoXiZhi-Screen) | <a href={useBaseUrl('/fonts/lxgw-neo-xihei-screen/LICENSE.txt')}>IPA Font License 1.0</a> |

霞鹜新晰黑屏幕阅读版由 IPA 字体衍生。其并入字体的许可见<a href={useBaseUrl('/fonts/lxgw-neo-xihei-screen/licenses_of_other_incorporated_fonts.txt')}>上游许可说明</a>。

## 使用原始 IPA 字体

如果希望将霞鹜字体换回原始 IPA 字体，可从 [IPA 官方下载页](https://moji.or.jp/ipafont/ipafontdownload/)获取并安装 **IPAexGothic（IPAex ゴシック）**，重新打开浏览器后访问本站。本站会优先使用本机已安装的 IPAexGothic，英文仍保留 Inter 和 IBM Plex Mono。

IPAexGothic 面向日文，部分汉字和标点的字形与中文字体不同。如需换回霞鹜，可卸载本机的 IPAexGothic 并重启浏览器。
